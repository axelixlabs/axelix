# Что такое Master?

Axelix Master (или просто «Master») — это центральный хаб экосистемы Axelix, сервис с расширенными возможностями для
управления и мониторинга сервисов на Spring Boot в различных средах.

## Основная задача

Axelix Master выступает в роли **централизованной консоли управления**, которая автоматически обнаруживает, регистрирует
и мониторит сервисы на Spring Boot, обеспечивая инсайты и контроль в реальном времени.

## Ключевые возможности

### 🔍 **Обнаружение сервисов**
Master узнаёт о приложениях на Spring Boot двумя взаимодополняющими способами:

**Самостоятельная регистрация (любая среда):**
Приложения, в которые подключён Axelix Spring Boot Starter, сами заявляют о себе Master и отправляют периодические
heartbeats. Это работает везде, где приложение может достучаться до Master, — Docker Compose, bare-metal, виртуальные
машины, Kubernetes и т.д. Механизм включается **отдельно для каждого приложения** (opt-in): активируйте его в своём
приложении через `axelix.sbs.discovery.self-registration=true` (по умолчанию выключен). Master принимает такие
регистрации из коробки (настройка `axelix.master.discovery.self-registration.enabled` в Master включена по умолчанию).

**Автоматическое обнаружение (только Kubernetes):**
Когда включено (управляется свойством `axelix.master.discovery.auto.enabled`), Master активно сканирует платформу в
поисках подходящих сервисов. Сканирование платформы на данный момент реализовано только для **Kubernetes**. В
собственной конфигурации Master оно выключено по умолчанию, но официальный
[Helm-чарт](https://github.com/axelixlabs/helm-charts/) включает его по умолчанию.

**Как работает обнаружение:**
1. **Самостоятельная регистрация**: приложения с Axelix Starter сами регистрируются и шлют heartbeats
2. **Сканирование платформы** (Kubernetes): Master опрашивает кластер в поисках сервисов, выставляющих эндпоинты Axelix SBS
3. **Мониторинг состояния**: Master периодически опрашивает зарегистрированные экземпляры и исключает те, что перестали слать heartbeats

Единое окно для всех ваших сервисов на Spring Boot:

**Включает в себя:**
- Дашборд со всеми зарегистрированными сервисами
- Встроенный MCP-сервер, отдающий эту информацию AI-агентам
- Инспекция свойств конфигурации и окружения
- Детальный анализ бинов
