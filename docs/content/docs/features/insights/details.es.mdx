***Página Details tal como aparece en la interfaz de Axelix***

La página está disponible para cualquier usuario autenticado: **VIEWER**, **EDITOR**, **ADMIN** y **SUPER_ADMIN** pueden abrirla e iniciar la exportación **Download state**. Los archivos de propiedades del entorno y de configuración incluidos en el archivo exportado siguen sujetos al enmascaramiento según los permisos de cada página: quienes no tienen `environment.values:read` / `config-properties.values:read` reciben `******` para esos valores. Consulte [Roles y permisos](../../setting-up-master-ui/authentication/authentication.mdx#roles-and-authorities) para ver la matriz completa de roles y permisos.

## Cabecera interna de información del servicio [#service-information-inner-header]
- **Instance Name**: el nombre de la instancia de la aplicación. El sufijo puede variar según el entorno de ejecución y de descubrimiento de Axelix Master.
- **Download state**: exporta el estado de la instancia como un archivo `.zip`, para analizar un problema más tarde o adjuntarlo a un informe de error.

### Componentes de Download state [#download-state-components]
En el cuadro de diálogo se elige qué incluir. Los elementos se agrupan en **JVM** y **Spring**:

- **Heap Dump**: todos los objetos en memoria, en un archivo `.hprof`. Para investigar fugas de memoria.
- **Thread Dump**: trazas de pila de todos los hilos. Para investigar bloqueos y contención.
- **Beans**: todos los beans con su ámbito, tipo y dependencias.
- **Caches**: gestores de cachés y cachés.
- **Conditions**: por qué se aplicó o no cada autoconfiguración.
- **Configuration Properties**: beans `@ConfigurationProperties` y sus valores enlazados, con los valores sensibles enmascarados.
- **Environment**: orígenes de propiedades por orden de precedencia, con los valores sensibles enmascarados.
- **Scheduled Tasks**: tareas cron, de frecuencia fija y de demora fija.

Antes de descargar, el cuadro de diálogo muestra el tamaño estimado del archivo. Todos los elementos, excepto el volcado del heap, ocupan menos de 1 MB. El volcado del heap ocupa aproximadamente lo mismo que el heap utilizado, a menudo cientos de MB, y la aplicación deja de responder mientras se escribe. El volcado también contiene todo lo que hay en memoria, incluidas contraseñas y tokens, por lo que debe almacenarse como una credencial.

#### Acceso al volcado del heap [#heap-dump-access]

<ReleasedInNotice version="1.3.0" />

A partir de Axelix 1.3.0, exportar un volcado del heap como parte del estado de la aplicación requiere el permiso `heap-dump:read`. Sin él, esta opción está deshabilitada, pero se pueden seguir exportando los demás componentes. `ADMIN` y `SUPER_ADMIN` tienen este permiso de forma predeterminada.

## Información de Git [#git-information]
Muestra metadatos del control de versiones, cuando están disponibles:

| Campo | Descripción | Ejemplo |
| --- | --- | --- |
| **Commit SHA** | Hash corto del commit | `a1b2c3d` |
| **Branch** | Nombre de la rama de Git | `main` |
| **Commit's Author** | Nombre del autor del commit | `John Doe` |
| **Author's Email** | Correo del autor del commit | `john@example.com` |
| **Commit's Timestamp** | Cuándo se realizó el commit | `2024-01-15T10:15:30Z` |

## Información de compilación [#build-information]
Muestra detalles de la compilación de la aplicación, cuando están disponibles:

| Campo | Descripción | Ejemplo |
| --- | --- | --- |
| **Artifact ID** | ID del artefacto Maven/Gradle | `spring-petclinic` |
| **Version** | Versión de la aplicación | `3.2.0` |
| **Group ID** | ID del grupo del proyecto | `org.springframework.samples` |
| **Build Timestamp** | Cuándo se compiló la aplicación | `2024-01-15T14:30:22Z` |

## Información del entorno de ejecución [#runtime-environment-information]
Información detallada de Java y del entorno de ejecución:

| Campo | Descripción | Ejemplo |
| --- | --- | --- |
| **Java** | Versión de la JVM | `17.0.17` |
| **Kotlin** | Versión de Kotlin <br/> (si la instancia utiliza Kotlin) | `1.9.22` |
| **JDK Vendor** | Proveedor de la distribución de Java | `Liberica`, `OpenJDK`, `Amazon Corretto` |
| **Garbage Collector** | GC activo en la aplicación | `G1`, `ZGC`, `GEN_SHENADOAH`, `EPSILONGC` |

## Detalles de Spring Framework [#spring-framework-details]
Versiones del ecosistema Spring:

| Campo | Descripción | Ejemplo |
| --- | --- | --- |
| **Spring Boot** | Versión de Spring Boot | `3.3.0` |
| **Spring Framework** | Versión del núcleo de Spring Framework | `6.2.0` |
| **Spring Cloud** | Versión de Spring Cloud (si se utiliza) | `2023.0.0` |

## Información del sistema operativo [#operating-system-information]
Detalles del sistema:

| Campo | Descripción | Ejemplo |
| --- | --- | --- |
| **OS Family** | Nombre del sistema operativo | `Linux`, `Windows Server` |
| **Kernel Version** | Versión del sistema operativo | `6.12.96`, `2022` |
| **CPU Architecture** | Arquitectura de CPU | `amd64`, `arm64` |
| **PID** | ID del proceso de la aplicación | `1` |
| **Process User** | Usuario del sistema operativo con el que se ejecuta el proceso de la aplicación | `root`, `app` |

**PID** y **Process User** aparecen a partir de Axelix 1.3.0. Conviene revisar un proceso que se ejecuta como `root` dentro de un contenedor, porque tiene más permisos de los que necesita la aplicación.

## Habilitar el endpoint dedicado de Actuator [#enable-dedicated-actuator-endpoint]

<LegacyNotice
  version="1.2.0"
  reason={<>En Axelix 1.2.0 o posterior, nada de esto es necesario: el starter registra por sí mismo sus endpoints personalizados de Actuator y Axelix ya no requiere habilitar los endpoints <code>health</code>/<code>info</code>. Funciona correctamente sin ellos. No se necesita ninguna configuración aquí.</>}
/>

La página utiliza el endpoint de Actuator `axelix-details`, aportado por Axelix Spring Boot Starter. Expóngalo mediante las propiedades estándar de Spring Boot Actuator. Consulte [Configuración de Spring Boot Starter](../../setting-up-spring-boot-service/spring-boot-starter/configuration.mdx) para ver la lista completa de endpoints de Axelix y el resto de la configuración:

<Tabs groupId="spring-config" items={['application.properties', 'application.yaml']}>
  <Tab value="application.properties">

```properties
management.endpoints.web.exposure.include=axelix-details
```

  </Tab>
  <Tab value="application.yaml">

```yaml
management:
  endpoints:
    web:
      exposure:
        include:
          - axelix-details
```

  </Tab>
</Tabs>
