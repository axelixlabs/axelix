***Thread Dump in der Axelix-Benutzeroberfläche***

Alle authentifizierten Benutzer, **VIEWER**, **EDITOR**, **ADMIN** und **SUPER_ADMIN**, können die Seite öffnen und
**Thread Contention Monitoring** umschalten. Die vollständige Rollen- und Berechtigungsmatrix finden Sie unter
[Rollen und Berechtigungen](../../setting-up-master-ui/authentication/authentication.mdx#rollen-und-berechtigungen).

Oben auf der Seite befinden sich drei Steuerelemente:

- Ein **Suchfeld**, das die Thread-Liste nach Namen filtert. Der Zähler daneben zeigt `<matching> / <total>`.
- Die Schaltfläche **Settings** <Image src="/img/feature/icons/settings-icon.png" alt="Einstellungen" width={20} height={20}/>,
  die einen Dialog mit dem Schalter **Thread Contention Monitoring** öffnet (siehe [Einstellungen](#einstellungen)).
- Eine verschiebbare **Zeitleiste**, mit der Sie den zu untersuchenden Zeitpunkt auswählen. Der dort ausgewählte
  Zeitraum bestimmt die darunter angezeigten Thread-Details.

Threads werden nach JVM-Priorität sortiert und als aufklappbare Einträge angezeigt. Der Kopf jedes Eintrags zeigt
Thread-Namen, aktuellen Zustand und eine farbige Zustandsanzeige (siehe [Farben der Thread-Zustände](#farben-der-thread-zustände)).

</ScreenshotsNotice>

***Thread-Dump-Details in der Axelix-Benutzeroberfläche***

Klappen Sie einen Thread auf, um seine detaillierte Momentaufnahme für den auf der Zeitleiste gewählten Zeitraum zu sehen:

- **Thread id**: die von der JVM vergebene Thread-Kennung.
- **Thread name**: der Thread-Name.
- **Thread state**: der JVM-Thread-Zustand (`RUNNABLE`, `BLOCKED`, `WAITING`, `TIMED_WAITING`, `TERMINATED`, …).
- **Priority**: die JVM-Thread-Priorität.
- **Blocked count**: die Gesamtzahl der Blockierungen des Threads. Nur bei aktiviertem **Thread Contention Monitoring**
  verfügbar, sonst als *Not Available* angezeigt.
- **Blocked time**: die vom Thread im blockierten Zustand verbrachte Zeit in Millisekunden. Nur bei aktiviertem
  **Thread Contention Monitoring** verfügbar, sonst als *Not Available* angezeigt.
- **Waited count**: die Gesamtzahl der Wartevorgänge des Threads auf eine Benachrichtigung. Nur bei aktiviertem
  **Thread Contention Monitoring** verfügbar, sonst als *Not Available* angezeigt.
- **Waited time**: die vom Thread wartend verbrachte Zeit in Millisekunden. Nur bei aktiviertem
  **Thread Contention Monitoring** verfügbar, sonst als *Not Available* angezeigt.
- **Daemon**: ob es sich um einen Daemon-Thread handelt.
- **Locked by**: gegebenenfalls Angaben zum Lock-Objekt, auf das der Thread wartet:
    - **Class**: der vollständig qualifizierte Klassenname des Lock-Objekts.
    - **Identity hash code**: der Identitäts-Hashcode des Lock-Objekts.
- **Stacktrace**: der für den ausgewählten Zeitpunkt erfasste Stacktrace.

## Einstellungen

Durch Klicken auf <Image src="/img/feature/icons/settings-icon.png" alt="Einstellungen" width={20} height={20}/>
öffnen Sie einen Dialog mit einem Schalter:

- **Thread Contention Monitoring** — aktiviert die JMX-Überwachung von Ressourcenkonflikten auf der `ThreadMXBean` der
  Instanz. Die JVM erfasst dann, wie lange jeder Thread in **BLOCKED** und **WAITING** verbracht hat. Dadurch werden
  die Felder `Blocked count` / `Blocked time` / `Waited count` / `Waited time` oben mit Werten gefüllt. Bei deaktivierter
  Überwachung bleiben diese vier Felder auf *Not Available*.

Die Überwachung verursacht messbaren zusätzlichen JVM-Aufwand. Deshalb bleibt sie auf Produktionsinstanzen
üblicherweise deaktiviert und wird nur für eine gezielte Untersuchung eingeschaltet.

## Dedizierten Actuator-Endpunkt aktivieren

<LegacyNotice
  version="1.2.0"
  reason={<>Ab Axelix 1.2.0 ist dies nicht mehr erforderlich: Der Starter registriert seine eigenen Actuator-Endpunkte
    selbst, und Axelix benötigt keine aktivierten <code>health</code>/<code>info</code>-Endpunkte mehr.
    Es funktioniert auch ohne diese Endpunkte. Hier ist keine Konfiguration erforderlich.</>}
/>

Diese Seite verwendet den Actuator-Endpunkt `axelix-thread-dump`, den der Axelix Spring Boot Starter bereitstellt.
Geben Sie ihn über die üblichen Spring Boot Actuator-Eigenschaften frei. Die vollständige Liste der Axelix-Endpunkte
und die zugehörige Einrichtung finden Sie unter [Spring Boot Starter konfigurieren](../../setting-up-spring-boot-service/spring-boot-starter/configuration.mdx).

<Tabs groupId="spring-config" items={['application.properties', 'application.yaml']}>
  <Tab value="application.properties">

```properties
management.endpoints.web.exposure.include=axelix-thread-dump
```

  </Tab>
  <Tab value="application.yaml">

```yaml
management:
  endpoints:
    web:
      exposure:
        include:
          - axelix-thread-dump
```

  </Tab>
</Tabs>
