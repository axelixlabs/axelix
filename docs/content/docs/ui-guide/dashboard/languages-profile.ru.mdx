***Профиль языков в интерфейсе Axelix***

В парке из десятков приложений каждое может работать на своей версии Java, с JDK своего поставщика, с Kotlin или без
него. Профиль языков показывает это сразу для всего парка: сколько приложений ещё на не-LTS версиях Java, сколько
поставщиков JDK используется и насколько распространён Kotlin.

Страница доступна только для чтения всем пользователям, прошедшим аутентификацию: ее могут открыть `VIEWER`, `EDITOR`,
`ADMIN` и `SUPER_ADMIN`. Полную матрицу ролей и полномочий см. в разделе [Роли и
полномочия](../../setting-up-master-ui/authentication/authentication.mdx#роли-и-полномочия).

## Что показывает страница

Сводка сверху показывает, сколько всего приложений в парке и сколько из них работают на LTS-версии Java, а сколько нет.

Ниже страница показывает:

- как приложения распределены по версиям Java, например Java `21` или `25`, и какие из версий LTS;
- на JDK каких поставщиков работают приложения, например Eclipse Temurin, Amazon Corretto или Azul Zulu;
- сколько приложений содержат код на Kotlin и как они распределены по версиям Kotlin, например `2.1`.

Если ни одно приложение не содержит кода на Kotlin, страница сообщает об этом вместо графиков по Kotlin.

## Как это работает

Master определяет версию Java, поставщика JDK и версию Kotlin каждого приложения во время выполнения. Он записывает их
раз в день и использует последнюю запись. Приложение учитывается один раз, сколько бы у него ни было инстансов.
Приложение, которое перестало выходить на связь, остаётся на странице с последними данными, которые оно сообщило.

Java 11 и 17 — LTS-версии, а начиная с Java 21 LTS становится каждая четвёртая версия: 21, 25, 29 и так далее. JDK,
которую Axelix не распознал, показывается как Unknown.
