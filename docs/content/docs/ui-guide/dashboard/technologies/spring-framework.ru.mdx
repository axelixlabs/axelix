Open Session in View (OSIV) держит сессию Hibernate и соединение с базой данных открытыми, пока формируется весь
HTTP-ответ. Ленивые ассоциации при этом незаметно загружаются вне транзакции, а каждый запрос держит соединение дольше,
чем нужно. Spring Boot включает OSIV по умолчанию в веб-приложениях с JPA, поэтому он часто остаётся включённым
случайно. Дашборд Spring Framework показывает, насколько он распространён в парке.

Страница доступна только для чтения всем пользователям, прошедшим аутентификацию: ее могут открыть `VIEWER`, `EDITOR`,
`ADMIN` и `SUPER_ADMIN`. Полную матрицу ролей и полномочий см. в разделе [Роли и
полномочия](../../../setting-up-master-ui/authentication/authentication.mdx#роли-и-полномочия).

## Что показывает страница

Страница показывает долю сервисов, которые работают с включённым OSIV, и долю тех, где он выключен.

## Как это работает

OSIV считается включённым, если в приложении зарегистрирован interceptor или filter Open Session in View. Master
записывает это раз в день и использует последнюю запись. Сервис учитывается один раз, сколько бы у него ни было
инстансов.
