***Spring Portfolio в интерфейсе Axelix***

У каждой ветки Spring Boot и Spring Framework (минорной версии, например `3.5.x`) ограниченное окно [OSS-поддержки](https://spring.io/support-policy).
Когда оно закрывается, ветка больше не получает релизов от сообщества, включая исправления безопасности: новые
[CVE](https://en.wikipedia.org/wiki/Common_Vulnerabilities_and_Exposures) в ней исправляются только по коммерческой подписке. В парке из
десятков приложений сложно понять, какие из них уже за этой датой и какие следующие. Spring Portfolio отвечает на это
сразу для всего парка.

Страница доступна только для чтения всем пользователям, прошедшим аутентификацию: ее могут открыть `VIEWER`, `EDITOR`,
`ADMIN` и `SUPER_ADMIN`. Полную матрицу ролей и полномочий см. в разделе [Роли и
полномочия](../../setting-up-master-ui/authentication/authentication.mdx#роли-и-полномочия).

## Что показывает страница

Сводка сверху показывает, сколько всего приложений в парке и у скольких из них уже закрыто окно OSS-поддержки.
Приложение считается поддерживаемым, только если и Spring Boot, и Spring Framework ещё получают OSS-обновления.

Ниже Spring Boot и Spring Framework показаны отдельно. Для каждого из них видно:

- сколько приложений работают на ветке с OSS-поддержкой;
- как приложения распределены по мажорным версиям и веткам, например `3.5.x`;
- получает ли каждая ветка OSS-обновления.

Последняя часть показывает окно OSS-поддержки каждой используемой ветки на шкале времени: когда ветка вышла, когда
заканчивается или закончилась её OSS-поддержка и сколько приложений на ней работают. Так видно, сколько времени
осталось до того, как следующие ветки выйдут из поддержки.

## Как это работает

Master раз в день записывает версии Spring Boot и Spring Framework каждого приложения и использует последнюю запись.
Приложение учитывается один раз, сколько бы у него ни было инстансов. Приложение, которое перестало выходить на связь,
остаётся на странице с последними версиями, которые оно сообщило.

Даты поддержки берутся из графиков, опубликованных командой Spring, например [окна поддержки Spring
Boot](https://spring.io/projects/spring-boot#support).
