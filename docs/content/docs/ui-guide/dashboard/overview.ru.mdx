В парке из десятков приложений сложно понять, какие версии ключевых компонентов в нём используются и какая из них
встречается чаще всего. Дашборд Overview отвечает на это сразу для всего парка и позволяет перейти от версии к списку
инстансов, которые на ней работают.

Страница доступна только для чтения всем пользователям, прошедшим аутентификацию: ее могут открыть `VIEWER`, `EDITOR`,
`ADMIN` и `SUPER_ADMIN`. Полную матрицу ролей и полномочий см. в разделе [Роли и
полномочия](../../setting-up-master-ui/authentication/authentication.mdx#роли-и-полномочия).

## Что показывает страница

Страница показывает, какие версии Spring Boot, Spring Framework, Java и Kotlin используются в парке и какая доля
инстансов работает на каждой из них:

- **Spring Boot** и **Spring Framework**: по веткам, например `3.5`.
- **Java**: по номеру версии, например `21`.
- **Kotlin**: по веткам, только среди инстансов, у которых Kotlin есть в classpath. Если таких в парке нет, Kotlin
  не показывается.

Для каждого компонента отдельно выделена самая распространённая версия.

## Переход к приложениям на Панели

Нажмите на версию, чтобы открыть [Панель](../wallboard.mdx) с фильтром по инстансам на этой версии, например
`Spring Boot = 3.5`. Чтобы открыть её в новой вкладке, удерживайте при нажатии Ctrl, Cmd или Shift.
