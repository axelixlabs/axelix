Axelix — это AI-native платформа с открытым исходным кодом для разработки и развития экосистем микросервисов на Java и Spring Boot.
Она создана разработчиками для разработчиков и помогает командам понимать отдельные приложения и управлять изменениями во всей экосистеме.

Axelix помогает:

- **Исследовать и отлаживать работающие приложения.** Изучать бины, источники конфигурации, транзакции, логи и другое состояние приложения.
- **Обнаруживать типичные проблемы.** Находить ошибки конфигурации Spring Boot и антипаттерны, влияющие на производительность, стабильность и безопасность.
- **Оценивать состояние зависимостей.** Проверять версии и статус поддержки библиотек в отдельных сервисах и во всей экосистеме.
- **Отслеживать миграции.** Следить за переходом сервисов на новые поколения Java и Spring Boot.
- **Наблюдать за выполнением `@Scheduled` и управлять им.** Изучать задачи, запускать их вручную, приостанавливать расписания и менять cron-выражения во время работы приложения.

AI-native означает, что Axelix изначально рассчитан и на инженеров, и на AI-агентов. Люди работают через веб-интерфейс,
а агенты используют встроенный сервер Model Context Protocol (MCP), чтобы изучать состояние приложений, исследовать
обнаруженные проблемы и выполнять доступные операции во время работы сервисов. Оба интерфейса учитывают настроенные права доступа.
В [каталоге MCP-инструментов](../setting-up-master-ui/mcp/mcp-tools.mdx) перечислены возможности, доступные агентам сейчас.

Нам важно, как быстро вы сможете запустить Axelix. Раздел [Установка](../start/getting-started.mdx) проведёт вас
через запуск Master, а руководство [Spring Boot Starter](../setting-up-spring-boot-service/spring-boot-starter/what-is-spring-boot-starter.mdx)
описывает добавление стартера в ваше приложение.

## Axelix OSS и Enterprise

Эта документация описывает как **Axelix OSS**, выпущенный под лицензией LGPL 3.0 с исходным кодом по адресу
[github.com/axelixlabs/axelix](https://github.com/axelixlabs/axelix), так и готовящуюся платную редакцию **Axelix
Enterprise** с дополнительными возможностями (в разработке — следите за новостями).
