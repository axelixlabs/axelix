Axelix es la plataforma de código abierto y nativa de IA para desarrollar y hacer evolucionar ecosistemas de microservicios Java con Spring Boot.
Creada por desarrolladores para desarrolladores, ayuda a los equipos a comprender cada aplicación y gestionar los cambios en sus servicios.

Axelix permite:

- **Inspeccionar y depurar aplicaciones en ejecución.** Explorar beans, fuentes de configuración, transacciones, registros y otros estados en tiempo de ejecución.
- **Detectar problemas habituales.** Encontrar errores de configuración de Spring Boot y antipatrones que afectan al rendimiento, la estabilidad y la seguridad.
- **Evaluar el estado de las dependencias.** Revisar las versiones de las bibliotecas y su estado de mantenimiento en cada servicio y en todo el ecosistema.
- **Seguir las migraciones.** Observar la adopción de generaciones de Java y Spring Boot en los servicios.
- **Supervisar y controlar las ejecuciones de `@Scheduled`.** Inspeccionar tareas, iniciar ejecuciones, pausar programaciones y cambiar expresiones cron en tiempo de ejecución.

Nativa de IA significa que Axelix está diseñada tanto para ingenieros como para agentes de IA. Las personas utilizan la interfaz web,
mientras que los agentes usan el servidor integrado de Model Context Protocol (MCP) para inspeccionar el estado de las aplicaciones, investigar los problemas
detectados y realizar las acciones admitidas en tiempo de ejecución. Ambas interfaces aplican los permisos de acceso configurados.
Consulte el [catálogo de herramientas MCP](../setting-up-master-ui/mcp/mcp-tools.mdx) para conocer las capacidades disponibles actualmente para los agentes.

Nos importa que pueda poner Axelix en marcha rápidamente. La guía de [instalación](../start/getting-started.mdx) explica
cómo iniciar Master, y la guía del [starter de Spring Boot](../setting-up-spring-boot-service/spring-boot-starter/what-is-spring-boot-starter.mdx)
explica cómo añadir el starter a la aplicación.
