Axelix est la plateforme open source conçue nativement pour l’IA, dédiée au développement et à l’évolution d’écosystèmes de microservices Java Spring Boot.
Créée par des développeurs pour des développeurs, elle aide les équipes à comprendre chaque application et à gérer les changements dans l’ensemble de leurs services.

Axelix vous aide à :

- **Inspecter et déboguer des applications en cours d’exécution.** Explorez les beans Spring, les sources de configuration, les transactions, les journaux et d’autres états d’exécution.
- **Détecter les problèmes courants.** Identifiez les erreurs de configuration Spring Boot et les antipatrons qui affectent les performances, la stabilité et la sécurité.
- **Évaluer la santé des dépendances.** Examinez les versions des bibliothèques et leur état de maintenance dans chaque service et dans tout l’écosystème.
- **Suivre les migrations.** Suivez l’adoption des générations de Java et de Spring Boot dans l’ensemble de vos services.
- **Surveiller et contrôler les exécutions de `@Scheduled`.** Inspectez les tâches, déclenchez des exécutions, suspendez des planifications et modifiez les expressions cron pendant l’exécution.

Conçue nativement pour l’IA, Axelix s’adresse aussi bien aux ingénieurs qu’aux agents IA. Les humains travaillent via l’interface web,
tandis que les agents utilisent le serveur Model Context Protocol (MCP) intégré pour inspecter l’état des applications, analyser les
problèmes détectés et effectuer les actions prises en charge pendant l’exécution. Les deux interfaces appliquent les autorisations d’accès configurées.
Consultez le [catalogue d’outils MCP](../setting-up-master-ui/mcp/mcp-tools.mdx) pour découvrir les fonctionnalités actuellement disponibles pour les agents.

Nous accordons une grande importance à la rapidité avec laquelle vous pouvez lancer Axelix. Le guide d’[installation](../start/getting-started.mdx) vous
accompagne dans la mise en route de Master, tandis que le guide [Spring Boot Starter](../setting-up-spring-boot-service/spring-boot-starter/what-is-spring-boot-starter.mdx)
explique comment ajouter le starter à votre application.

## Axelix OSS et Enterprise

Cette documentation couvre à la fois **Axelix OSS**, publié sous licence LGPL 3.0 et dont les sources sont disponibles sur
[github.com/axelixlabs/axelix](https://github.com/axelixlabs/axelix), et la future édition payante **Axelix Enterprise**,
qui proposera des fonctionnalités supplémentaires (en cours de développement, restez à l’écoute des nouveautés).
